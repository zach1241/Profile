# Additional portfolio pages

The original single-page portfolio remains the homepage. No framework or build process is required.

- **Homepage**: `index.html`, original design preserved except adding Projects and Writing navigation links and an anchor-navigation safeguard.
- **Secondary styles**: `site.css`, using the exact homepage CSS followed by a small set of editorial page patterns.
- **Projects**: `projects/index.html` and six individual case studies.
- **Blog**: `blog/index.html` and nine editorial field notes, with client-side topic filters and search.
- **SEO**: static crawlable HTML, page metadata, canonical URLs and `sitemap.xml`.

To add a page, copy an existing page from the same directory and keep the navigation, typographic scale, footer and neutral palette. Do not replace the homepage or introduce a second visual system. Project and article descriptions avoid unverified outcomes. Confirm client permissions before adding sensitive screenshots or results.
