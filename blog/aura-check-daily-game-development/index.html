Building Aura Check: the challenge of a daily game

Short sessions, fair scores and the question of what makes somebody return tomorrow.

By Zachary Swanepoel14 October 20265 min read

Short sessions, fair scores and the question of what makes somebody return tomorrow.

Why a daily game

I wanted Aura Check to feel like something you could play quickly and share, rather than another game demanding an entire evening. The idea is simple: a short challenge, a score, and a reason to compare with friends.

That simplicity turns out to create interesting technical questions. What counts as a daily attempt? How should guests be treated? Can someone manipulate their score?

The work behind the game

The app uses a React-based frontend with a Supabase backend. I have explored server-side score submission, daily attempts, friend challenges, leaderboards and rate limiting to protect the competitive experience.

A shareable challenge also needs to work for someone who did not arrive with an account. Every extra sign-in requirement is an interruption to the fun.

Personal perspective

My take

I want to see whether the core game earns a repeat visit before I surround it with monetization. A small, fun loop is worth more than a long features list nobody returns to use.
